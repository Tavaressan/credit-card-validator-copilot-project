# Credit Card Validator Copilot Project

A JavaScript project for validating credit card labels, developed with the assistance of GitHub Copilot.

## 📋 Description

This project implements a function in JavaScript that validates credit card labels by checking the card number against patterns corresponding to known providers.

Supported credit card labels include:

- **MasterCard**
- **Visa**
- **American Express**
- **Diners Club**
- **Discover**
- **enRoute**
- **JCB**
- **Voyager**
- **Hipercard**
- **Aura**

The validation is based on regex pattern matching for each card type.
